# Swift Construction & Painting

Production website for Swift Construction & Painting, serving Hernando, Citrus and Pasco Counties in Florida.

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production Build

```bash
npm run build
npm run start
```

## Vercel Deployment

Import this repository into Vercel and use the detected Next.js settings. No custom build command or output directory is required.

Before connecting the production domain, confirm that `https://swiftconstructionandpainting.com` is the final canonical domain. The sitemap, robots file, structured data and canonical URLs use that address.
